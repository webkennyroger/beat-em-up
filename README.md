# Final Fight SNES Clone

Projeto do Discord RETRODEVBR focado em recriar a arquitetura de beat em up do Super Nintendo usando:

- PVSnesLib
- C
- Assembly 65816
- DMA Queue
- Sprite Streaming
- VRAM Management
- Multi-layer backgrounds
- AI inimigos
- HUD dinâmico

---

# Objetivos

- recriar pipeline SNES real
- estudar OAM
- estudar DMA
- estudar animações SNES
- criar engine reutilizável
